PART 01 · THEORY

개념 확인

시각적 위계와 게슈탈트 법칙의 기본 원리를 확인합니다.

QUESTION 01

UI 디자인에서 ‘시각적 위계(Visual Hierarchy)’가 필요한 이유로 가장 알맞은 것은?

정답 B
시각적 위계는 사용자가 무엇을 먼저 보고 다음으로 어디를 볼지 안내합니다. 크기·굵기·색상 대비·위치·여백·이미지 크기 등이 위계를 만드는 방법입니다.
QUESTION 02

시각적 위계를 만들 때 수업에서 강조한 ‘주의할 점’은 무엇인가?

정답 C
모든 요소를 강하게 강조하면 강조의 차이가 사라집니다. 중요한 정보와 덜 중요한 정보 사이에 차이를 만들어야 위계가 생깁니다.
QUESTION 03

게슈탈트의 법칙을 배우는 가장 중요한 이유는?

정답 B
게슈탈트 법칙의 목적은 이름 암기가 아니라 사용자가 화면을 어떻게 인식하는지 이해하고 UI 설계에 활용하는 것입니다.
QUESTION 04

관련된 정보는 가깝게 배치하고, 다른 정보와는 더 큰 여백을 두었다. 가장 직접적으로 활용한 법칙은?

정답 A · 근접성
가까운 요소는 같은 그룹으로, 멀리 떨어진 요소는 다른 그룹으로 인식하기 쉽습니다. 그래서 여백도 정보 관계를 보여주는 디자인 요소입니다.
QUESTION 05

같은 역할의 버튼을 페이지 전체에서 같은 색·형태·크기로 반복하는 것과 가장 관련 있는 법칙은?

정답 B · 유사성
비슷한 색과 형태를 가진 요소는 같은 역할이나 같은 종류의 정보로 인식하기 쉽습니다.
QUESTION 06

다음 중 ‘공통영역’과 ‘근접성’을 가장 정확하게 구분한 설명은?

정답 B
근접성은 요소 사이의 거리, 공통영역은 같은 배경이나 경계가 그룹을 만드는 핵심 단서입니다.
QUESTION 07

형태가 일부 끊겨 있어도 뇌가 빠진 부분을 채워 완성된 모양으로 인식하는 법칙은?

정답 C · 폐쇄성
불완전한 형태에서도 빠진 부분을 보완해 하나의 완성된 형태로 인식합니다. 로고·아이콘·그래픽에서 자주 확인할 수 있습니다.
PART 02 · APPLICATION

UI 적용 문제

이제 화면의 어느 부분 때문에 그렇게 보이는지 판단합니다.

BEST MENU

QUESTION 10

같은 배경 박스 안의 요소들이 하나의 기능 그룹처럼 보입니다. 가장 직접적인 법칙은?

정답 B · 공통영역
하나의 배경 영역이 직접적인 시각적 경계를 만듭니다. 점의 형태가 같기 때문에 유사성도 작동하지만, 이 문제의 가장 강한 단서는 영역입니다.
