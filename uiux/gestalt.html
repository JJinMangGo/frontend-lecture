PART 02 · GESTALT

게슈탈트의 법칙이란?

인간이 시각적 요소를 각각 따로 보기보다 하나의 의미 있는 전체 형태로 묶어서 인지하는 방식을 설명하는 심리학 원리입니다.

법칙 이름을 외우는 것이 목표가 아닙니다. 화면에서 왜 그렇게 보이는지 설명할 수 있어야 합니다.
01 · PROXIMITY

근접성 — 가까이 있으면 같은 그룹으로 봅니다.

${''.repeat(12)}
  • 가까운 요소들을 자동으로 하나의 그룹으로 묶어 인식합니다.
  • 모양이나 색이 달라도 거리가 가까우면 한 집합처럼 보일 수 있습니다.
  • 멀리 떨어지면 서로 독립된 정보로 인식하기 쉽습니다.

UI 적용: 상품명·설명·가격처럼 관련된 정보는 가깝게, 다음 상품이나 다른 섹션과는 더 큰 여백으로 구분합니다.

02 · SIMILARITY

유사성 — 비슷하게 생기면 같은 역할로 봅니다.

  • 색, 형태, 크기, 스타일이 비슷한 요소에서 패턴과 연관성을 찾습니다.
  • 멀리 떨어져 있어도 시각적 특성이 같으면 같은 종류로 인식할 수 있습니다.

UI 적용: 같은 역할의 버튼, 카드, 메뉴는 같은 시각 규칙을 반복해 사용자가 역할을 빠르게 이해하게 합니다.

03 · CLOSURE

폐쇄성 — 일부가 없어도 완성된 형태로 봅니다.

선이나 형태가 완전히 이어져 있지 않아도 뇌는 빠진 부분을 채워 하나의 완전한 형태로 인식하려는 경향이 있습니다.

UI 적용: 일반적인 레이아웃보다 로고, 아이콘, 그래픽 표현에서 더 쉽게 확인할 수 있습니다.

04 · COMMON REGION

공통영역 — 같은 영역 안에 있으면 한 그룹으로 봅니다.

같은 배경색, 박스, 경계 안에 들어간 요소는 하나의 그룹으로 인식하기 쉽습니다.

UI 적용: 섹션 배경색이나 카드 경계로 콘텐츠를 구분할 수 있습니다. 단, 모든 정보를 카드로 감쌀 필요는 없습니다. 여백만으로도 충분히 그룹화할 수 있습니다.

05 · CONTINUITY

연속성 — 시선은 이어지는 방향을 따라갑니다.

ITEM 01설명 텍스트
ITEM 02설명 텍스트
ITEM 03설명 텍스트
ITEM 04설명 텍스트
  • 시선은 갑자기 꺾이기보다 부드럽게 이어지는 선과 배열을 따라갑니다.
  • 같은 방향으로 반복되는 요소를 하나의 흐름으로 인식합니다.

UI 적용: 리스트, 퀵메뉴, 가로 캐러셀에서 다음 카드 일부를 노출하면 오른쪽으로 콘텐츠가 계속된다는 단서가 됩니다.

06 · PRÄGNANZ

간결성 — 복잡한 형태도 가능한 단순하게 이해합니다.

뇌는 복잡하거나 겹친 형태를 그대로 조각조각 해석하기보다 대칭적이고 규칙적이며 단순한 형태로 정리해 이해하려는 경향이 있습니다.

예: 겹쳐 있는 수많은 곡선 조각보다 ‘겹쳐진 다섯 개의 원’처럼 단순한 전체 구조로 인식합니다.

07 · FIGURE–GROUND

전경과 배경 — 무엇이 주인공이고 무엇이 배경인지 구분합니다.

새로운 경험을 만나보세요

이미지 위에서도 핵심 메시지와 행동이 먼저 보여야 합니다.

사용자는 화면에서 주목해야 할 대상(전경)과 그 뒤를 받치는 영역(배경)을 구분합니다.

UI 적용: 배너, 포스터, 광고 콘텐츠처럼 이미지 위에 텍스트와 CTA가 올라가는 화면에서 특히 확인하기 쉽습니다.

REMEMBER

여백은 남는 공간이 아닙니다.

무엇이 같은 그룹이고 무엇이 다른 그룹인지 알려주는 디자인 요소입니다.

PART 03 · PRACTICE

이제 화면에서 직접 찾아보세요.

한 화면에는 여러 법칙이 동시에 작동할 수 있습니다. 법칙 이름뿐 아니라 어떤 시각적 근거 때문에 그렇게 판단했는지 생각해보세요.

QUESTION 01

아래 상품 목록에서 가장 분명하게 함께 작동하는 법칙 두 가지는?

Strawberry Cake부드러운 크림과 딸기
Chocolate Cake진한 초콜릿의 풍미
Cheese Cake고소하고 부드러운 치즈
근접성 + 유사성
각 상품의 이미지·상품명·설명이 가까워 하나의 상품 정보로 묶이고, 세 상품이 같은 크기와 구조를 반복해 같은 종류의 콘텐츠로 인식됩니다.
QUESTION 02

같은 배경 박스 안의 아이콘들이 하나의 기능 그룹처럼 보이는 가장 직접적인 이유는?

공통영역
요소들이 하나의 배경 영역 안에 포함되어 있어 같은 그룹이라는 경계가 직접적으로 만들어집니다. 아이콘 형태가 같기 때문에 유사성도 함께 작동할 수 있습니다.
