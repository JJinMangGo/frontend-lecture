# 인터랙션 · 모션 스펙

원칙: 유리는 **물성**으로 반응한다. 요소 크기를 키우는 대신 굴절·광원·깊이를 바꾼다. 모든 값은 시작점이며, 화면에서 보고 조정한다.

## 상태별 물성 테이블

| 상태 | 바꾸는 것 | 값 | 지속 |
| --- | --- | --- | --- |
| rest | — | tint 7%, blur 14px, scale 기준값 | — |
| hover | 광원 이동 + 상승 | `--lg-mx/--lg-my` 포인터 추적, `translateY(-2px)` | 420ms spring |
| press | 두께 압축 | `scale(0.994)`, 그림자 60%로 축소 | 180ms |
| focus-visible | 링 | `outline: 2px` + offset 3px (절대 제거 금지) | 180ms |
| drag | 굴절 증가 | 필터 `scale` +40% | 240ms |
| exit | 굴절 소멸 | 필터 `scale` → 0, 그다음 opacity | 320ms |

이징: 진입/상승은 `cubic-bezier(0.22, 1, 0.36, 1)`, 물성 있는 반동은 `linear()` 스프링(`--lg-ease-spring`). `ease-in-out` 기본값은 쓰지 않는다.

## 반드시 구현할 것

1. **포인터 추적 스펙큘러** — 표면마다 광원이 커서를 따라온다. `pointermove` → CSS 변수 → `requestAnimationFrame` 1회 쓰기. `assets/glass-component.html` 의 스크립트가 그대로 쓰는 배선이다.
2. **스크롤 반응** — 상단 바/시트는 스크롤에 따라 blur 와 tint 만 보간한다(0→14px, 0→8%). 색을 갑자기 갈아끼우지 않는다.
3. **레이아웃 연속성** — 카드→상세 전환은 `view-transition-name` 으로 같은 유리판이 이동/확장되게 한다. 페이드 교차는 쓰지 않는다.
4. **정지 상태에서도 살아 있게** — 배경 그라디언트를 40~80초 주기로 아주 느리게 움직인다. 유리는 정지, 배경이 흐른다.
5. **접근성 게이트** — `prefers-reduced-motion: reduce` 에서 포인터 추적과 상승을 끄고 상태 변화는 즉시 반영한다. 유리 위 텍스트는 흰 텍스트 기준 대비 4.5:1 이상을 실제 배경 위에서 확인한다. 대비가 부족하면 tint 를 올리는 대신 콘텐츠 뒤에 국소 어두운 스크림을 깐다.

## 하지 말 것

- 요소 하나에 blur + 그림자 + sheen + 굴절 + 보더 + 글로우를 모두 쌓기. 표면 하나당 강조는 하나.
- 모든 카드를 유리로 만들기. 유리는 부유하는 것(내비, 시트, 오버레이, 히어로 카드)에만. 본문/폼 필드는 불투명.
- 유리 위에 또 유리 올리기(2단 이상). 두 판이 겹치면 블러가 중첩돼 탁해진다.
- 굴절을 세게 걸고 그 위에 작은 텍스트 올리기. 굴절되는 것은 배경뿐이어야 한다.
- 애니메이션되는 그라디언트 보더, 무지개 글로우, 이모지 아이콘, 떠다니는 파티클 — 즉시 AI 느낌으로 읽힌다.
