# CSS 결합 선택자 퀴즈 구조 명세서

UI 스타일뿐만 아니라 퀴즈의 핵심인 상태 관리와 네비게이션 로직까지 모두 포함한 컴포넌트 전체 구조 명세입니다. 

## 1. UI 스타일 및 레이아웃 (CSS)
기본적인 UI 컴포넌트의 디자인 규칙입니다.

* **전체 테마:** 밝은 배경(`#f0f4f8`)에 카드형 레이아웃 구성
* **상단 진행률 바 (`.prog-bg`, `.prog-fill`):** 전체 컨테이너 상단에 얇고 둥근 막대 형태로 배치되며, 문제 풀이 진행도에 따라 파란색(`#4361ee`) 막대의 너비(`width`)가 부드럽게(`transition`) 차오름
* **문항 메타 정보 (`.q-meta`):**
  * **문항 번호 (`.q-num`):** 현재 문항과 전체 문항 수를 보여주는 회색 톤(`#94a3b8`)의 텍스트
  * **카테고리 태그 (`.q-cat`):** 문제의 유형을 나타내는 알약 형태(Pill shape)의 뱃지. 연한 파란색 배경(`#eef2ff`)과 짙은 남색 텍스트(`#3730a3`)로 시각적 분리감 제공
* **가계도(Tree) 영역 (`.tree-wrap`):** 코드 분석을 돕기 위해 모노스페이스 폰트(`Courier New`) 적용, 트리 계층별로 글자 색상(파랑, 청록, 보라 등)을 다르게 주어 직관성 확보
* **코드 및 힌트 블록:** 
  * 힌트(`.hint-box`): 좌측 파란색 보더 라인으로 시선 유도
  * 코드(`.code-block`): 다크 테마 배경(`#1e1e2e`)으로 코드 가독성 향상
* **선택지 버튼 (`.opt-btn`):** 
  * 기본: 흰색 배경
  * Hover 시: 연한 파란색 배경 (`#eef2ff`)
  * 정답 시 (`.correct`): 녹색 톤 (`#f0fdf4` 배경, `#16a34a` 테두리)
  * 오답 시 (`.wrong`): 붉은색 톤 (`#fef2f2` 배경, `#dc2626` 테두리)
* **결과창 (`.score-box`):** 텍스트 크기와 그리드(`display: grid`)를 활용해 정답, 오답, 미응답 횟수를 직관적으로 배치

## 2. 데이터 구조 (Quiz Data)
퀴즈 문항을 관리하는 `Q` 배열의 내부 객체 구조입니다.

* `cat`: 카테고리 (예: '가계도 이해', '자손 선택자')
* `q`: 퀴즈 문항 텍스트
* `tree`: HTML 계층 구조를 보여주는 가계도 텍스트 (줄바꿈 `
` 포함)
* `code`: 예시 CSS 코드 (없을 경우 `null`)
* `hint`: 문제 풀이에 도움을 주는 핵심 개념 텍스트
* `opts`: 4개의 선택지 텍스트가 담긴 배열
* `ans`: 정답 인덱스 (0~3)
* `ex`: 문제 풀이 후 노출되는 해설 텍스트

---

## 3. 상태 관리 (State)
퀴즈 진행 상황을 추적하는 핵심 전역 변수들입니다.

* `cur` (Number): 현재 진행 중인 퀴즈 문항의 인덱스 (기본값: `0`)
* `answered` (Array): 문항별 정답/오답 여부를 저장 (`'correct'`, `'wrong'`, 또는 `null`)
* `sel` (Array): 사용자가 선택한 보기의 인덱스를 저장

---

## 4. 핵심 기능 (Functions)
UI 렌더링 및 네비게이션 작동 방식입니다.

### `render()`
* 현재 문항(`cur`)에 맞춰 화면(DOM)을 다시 그리는 메인 함수.
* 진행률 바, 가계도, 힌트, 코드, 선택지 버튼 등을 조건에 따라 생성하여 `#qa` 컨테이너에 삽입.
* 이미 푼 문제(`answered[cur] !== null`)인 경우 정답/오답 스타일을 즉시 반영하고 버튼 클릭을 비활성화.
* 해설(`.explanation`) 영역은 문제 풀이 완료 시에만 노출.

### `choose(i)`
* 사용자가 선택지를 클릭했을 때 실행되는 함수.
* 이미 푼 문제라면 무시하고, 그렇지 않다면 선택한 인덱스와 정답 여부를 상태 변수에 업데이트한 뒤 `render()`를 재호출.

### `go(d)`
* 이전/다음 버튼 클릭 시 문항 인덱스(`cur`)를 `d`만큼 증감시키는 함수.
* 첫 문제나 마지막 문제 범위를 벗어나지 않도록 `Math.max/min` 처리 후 `render()` 재호출.

### `renderScore(root)`
* 모든 문제를 다 풀거나 결과 보기로 진입했을 때 실행.
* 점수(%) 구간에 따른 맞춤형 피드백 메시지 제공 (90% 이상, 70% 이상 등).
* 전체 정답/오답/미응답 개수를 그리드로 출력하고 '처음부터 다시 풀기' 버튼 활성화.
